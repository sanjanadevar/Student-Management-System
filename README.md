# 🎓 Student Management System

A simple **Java-based Student Management System** developed using **Object-Oriented Programming (OOP)** concepts. This console-based application allows users to store, manage, and manipulate student records efficiently.

The system provides functionalities to add, view, search, update, and delete student information. This project was developed to understand fundamental programming concepts, data handling, and problem-solving techniques using Java.

---

## 📌 Project Overview

The **Student Management System** is designed to manage student details such as:

- Student ID
- Student Name
- Student Marks

The application follows an object-oriented approach by separating student data and management operations into different classes.

This project demonstrates the implementation of Java concepts like classes, objects, encapsulation, methods, and collections.

---

## ✨ Features

### ➕ Add Student
- Add new student records.
- Store student ID, name, and marks.

### 📄 View Students
- Display all student records stored in the system.

### 🔍 Search Student
- Search for a student using their unique ID.

### ✏️ Update Student
- Update existing student information such as name and marks.

### 🗑️ Delete Student
- Remove student records from the system using student ID.

### 🚪 Exit
- Exit the application safely.

## ⚙️ How to Run the Project

### Prerequisites

Make sure you have:

- Java Development Kit (JDK) installed
- A code editor such as VS Code or IntelliJ IDEA

Check Java installation:

```bash
java -version
```

---

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/Student-Management-System.git
```

---

### Step 2: Navigate to the Project Folder

```bash
cd Student-Management-System
```

---

### Step 3: Compile the Java Files

```bash
javac *.java
```

---

### Step 4: Run the Application

```bash
java Main
```
